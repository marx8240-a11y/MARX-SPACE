# Simple Weather Web App (Python)

A small Python web app that lets you search for a city and get current weather information.

## Features
- Search by city name
- Current temperature, feels-like temperature, humidity, wind speed
- Human-readable weather condition
- No third-party Python dependencies

## Data source
- Geocoding + weather from [Open-Meteo](https://open-meteo.com/) (no API key needed)

## Run locally

```bash
python3 app.py
```

Open: `http://localhost:5000`
